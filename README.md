# Library

This is a front-end application that shows books.

## Pre-requisites

Please make sure you are using Node version 16.20.2

## Technologies Used

- HTML
- CSS
- JavaScript
- React

## How To Run In Development Mode

To start the application on localhost:

```bash
npm i && npm start
```

## Best Practices

- Make sure to follow [BEM naming conventions](https://getbem.com/naming/) for CSS class names
